# Agora Web Application

**Agora** is a web-based e-commerce platform in a prototype stage.

---

## Features

- User registration and login system
- Admin, Buyer and seller accounts
- Product listings with images and descriptions
- Business account management
- Store creation and product management for sellers
- MySQL database integration

---

## Tech Stack

- **Frontend**: HTML, CSS (Tailwind), JavaScript
- **Backend**: PHP
- **Database**: MySQL (via XAMPP)
- **Environment**: XAMPP local server

---

## Setup Instructions

1. 'npm install'
2. Move Agora directory to 'C:\xampp\htdocs\'
3. Start Apache and MySQL from the XAMPP Control Panel
4. Import the SQL database if needed (http://localhost/Agora/build.php)

## Site Instructions

1. http://localhost/Agora/html/index.html
2. Register a Administrator Role
3. Create a Store
4. Invite Buyers/Sellers to use buisiness
5. Assign a seller-ID to operate a store (Create/Manage Store)
