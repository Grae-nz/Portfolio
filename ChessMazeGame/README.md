# Kiki Endless Runner

A 2D endless runner game built in Unity (C#) where you guide Kiki the cat!

![screenshot](screenshot.png)

---

## Features

- Infinite side-scrolling gameplay
- Randomized obstacle generation
- Collection system
- Score tracking

---

## How to Play

- **Jump**: Press left mouse button
- Avoid obstacles
- Collect birds and mice to gain points

---

## How to Run the Game

1. Download the kiki.zip file and extract
2. Run 'Kiki High-Fidelity V3.exe'
   
Or

1. Open the Kiki Endless Runner directory in Unity
2. Open the scene MainMenu
3. Press Play in the Unity editor
